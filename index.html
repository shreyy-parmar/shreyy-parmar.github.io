01about

I'm an Azure Data Engineer based in Toronto, currently building data platforms at Bell. My work centers on ingesting, transforming, and governing data across Azure Data Factory, Databricks, and Microsoft Fabric — usually landing in a medallion architecture on Delta Lake.

Before Bell, I worked as a Data Engineer at Techmicra IT Solutions, building ETL pipelines and supporting real-time ingestion and data governance work. I hold an MSc in Computer Science from Lakehead University and a Bachelor's in Computer Engineering from Gujarat Technological University, along with the Databricks Certified Data Engineer Associate and Microsoft DP-900 certifications.

Outside of client work, I build end-to-end pipeline projects — from REST API ingestion through Synapse and Fabric to Power BI dashboards — to keep hands-on with the platform as it evolves.
